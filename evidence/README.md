# 现场资料与运行记录

本目录在公开仓库中保留经脱敏的开发证据，详细文件范围见 [index.json](index.json)。

- `recordings/`：三段录制的完整 samples、waypoints、metadata 及文本动作文件。
  保留原有时间和数值，不将它们自动导入活动控制目录。
- `logs/`：示教、回放和开发运行日志。小文件完整保留；超过 2 MB 的高频日志
  截取前 32 条和后 32 条记录，原文件字节数和截取方式逐文件记录于清单。
  截取日志不能用于重建完整时间序列，也不能代表完整运行结果。
- [现场照片](../arm-button/web/reference.png)：原照片中胸前的机构标识已用不透明色块遮盖。
  使用内置 imagegen 图像编辑；该图是脱敏后的 AI 编辑副本，不是未经修改的测量证据。

照片编辑提示：仅以不透明深灰色矩形遮盖机器人胸前贴纸的图标及全部中英文字，
不添加新文字或品牌，保留机器人姿态、支架、场景、照明和构图。

日志中的组织名称、网络地址、个人路径和凭据字段已脱敏；数值测试结果与历史日期保留。
录制仅供研究开发参考，不构成直接执行许可。容器镜像包、SDK 库、可执行二进制
和模型权重没有加入本目录。
