# 原页面中的 DreamControl 动作控制

2026-10-15。入口为 <http://127.0.0.1:8770/>。原几何预览保留在动作面板下方，关节滑条仍仅编辑离线模型。新面板使用已验证的上肢策略、HG / PR 报文及 `rt/arm_sdk`；没有接入手指或导航。

## 使用

1. 修改 XYZ（m），或选择 z=0.31 / 0.50 预设；默认 `[0.50, -0.23, 0.31]`。坐标原点是机器人根部，X 向前、Y 向左、Z 向上，Z 不是离地高度。“保存坐标”不连接或运动。
2. 点击“连接读取”。这里只读取状态快照，不停服、接管或发布动作。真正开始时会重新检查实时状态。
3. 整组执行：选择“完成全部动作并交还”，点击“整组执行一次”。只执行一次，不循环、不自动重试。也可选择某节点作为本次终点，在该处停留。
4. 分段调试：点击“单独准备”，依次使用“执行抬手 → 执行按压段 → 执行撤回 → 执行放下 → 交还控制权”。每段结束停留。从空闲直接点“执行抬手”会先完成准备。后续段要求前一节点完成，不能从放下姿态直接跳到按压。
5. 动作中可“暂停保持”并“继续当前段”；在节点可“继续至整组结束”。“返回默认姿态并交还”是从当前实测姿态做 2 秒归位；“停止并交还控制权”只退权重，不自动归位。准备接管阶段只允许停止交还，避免突然将未完成的接管权重设为 1。

现场保持清空、有人监护且手柄可用。手柄 select 由 native 适配器直接检查，可中止。页面打开和服务器启动都不会连接机器人。

## 节点定义

| 阶段 | 策略时间 / 时长 | 结束节点 |
|---|---|---|
| 实测姿态接管、默认姿态过渡 | 2 + 2 秒 | 准备完成 |
| 抬手 | 0.00–2.24 秒，112 组采样 | 抬手节点 |
| 按压段 | 2.24–3.64 秒，70 组采样 | 按压段结束 |
| 撤回 | 3.64–10.00 秒，318 组采样 | 撤回节点 |
| 返回默认姿态 | 2 秒 | 放下节点 |
| 退权重、零权重帧 | 约 1.2 秒 | 已交还 |

分段边界根据作者 BUTTON_PRESS_TIME=2.925 秒及其 ±0.7 秒窗口，按 50 Hz 采样取整。这些是策略时间节点，不是逆解得到的精确笛卡尔航点，也不是实体按钮触发信号。

暂停 / 节点停留使用进入停留时的实测上肢姿态，继续发送保持指令，策略时钟和 previous action 冻结。恢复时用 0.3 秒混合过渡，再接续当前策略时间。每次停留最多 20 秒；页面心跳超过 3 秒未到、会话接近 90 秒或 native 检查异常时退出并交还，不自动重试。新 native 仅通过显式 `--max-seconds 90` 为交互模式启用 90 秒上限；原 CLI 默认仍为 25 秒，旧不可变部署和日志保留。

输入范围 X 0.43–0.54、Y -0.27–-0.13 来自固定版本上游真机按钮入口的限幅；Z 下限 0.13 同上，上限扩展至已测试的 0.50。这是界面输入范围，不能当作已标定安全工作空间。仅两个 `[0.50, -0.23, 0.31 / 0.50]` 配置有此前整组真机记录；其他组合和新节点停留尚未实物验收。

## 启动与部署

本机服务器仅绑定回环地址，SSH 继续使用既有迁移密钥路径，不复制密钥内容。真机后端必须显式启用 `--allow-control`；默认启动是无机器人界面模拟。

```powershell
& 'C:/Users/developer/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' `
  '<PROJECT_ROOT>/arm-button/server.py' `
  --backend ssh --allow-control --port 8770 `
  --ssh-key "$env:TEMP/g1-migration-20261013/id_ed25519"
```

新版本部署记录、MuJoCo 验证和界面验收保存在 `artifacts/dreamcontrol-console-20261015`。`arm-button/dreamcontrol-runtime.json` 指向独立不可变版本；该配置不包含凭据。服务器启动不访问 SSH 或 DDS，只有用户点击连接 / 执行时才访问对应接口。
