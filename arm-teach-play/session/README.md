## 操作

1. 保持吊架/防倾保护，持续支撑左右手臂，监护者持遥控器。
2. 点击“进入低阻尼并开始录制”。实测初姿接管约 2 秒，随后约 2 秒降低双臂位置刚度，期间继续托臂。
3. 显示“录制中”后手动摆臂，连续角度自动记录；输入名称并点击“保存当前关键点”可标记初姿、按钮前、按压终点、撤离和回正。
4. 首轮先做小范围空载摆臂，核对录制与停止后再逐段增加动作。
5. 点击“结束录制并交还”，继续托臂，等待显示已发送零权重，并由现场确认站稳。

首轮客户端控制约 85 秒结束，原生接口独立上限 90 秒。浏览器心跳超过 3 秒、原生输入超过 0.25 秒未更新、状态过期、机型变化、模式/服务异常、其他上肢写入或电机状态异常会结束会话。遥控器 Select 可中止。软件停止不是硬件急停，也不保证任意情况下身体平衡。没有自动重启或回放。

## 适配与边界

从项目中已有实机验证的 DreamControl HG 传输独立派生，补齐机型、PR、17 个有效上肢字段、CRC、单一写入者检查与看门狗。原调试台和事件锁未修改。

双臂以既有传输 kp=40/kd=10 从实测初姿接管，再渐变为 kp=0/kd=0.8；tau=0，不声称主动重力补偿或松手悬停。腰部保持初姿，沿用 kp=200/kd=5。这些是实现参数，不是官方安全范围。仅发布 rt/arm_sdk；下肢由常规运控管理，不发送底盘或手指动作。

编译、无 DDS 报文自检与启动后只读核验通过。低阻尼切换、拖动与结束交还尚未实机验收。本入口提供双臂录制，不提供回放或仅右臂模式。

## 数据

每次控制台启动建立独立的 `arm-teach-play/recordings/<UTC时间>/` 目录，避免覆盖。当前目录见 [console-runtime.json](console-runtime.json)。

- `transport.jsonl`：原生状态、命令与结束证据，包含准备阶段。
- `samples.jsonl`：开始后的连续实测角度/速度与时间戳，采样设计目标 50 Hz，实际频率以时间戳为准。
- `waypoints.json`：人工标记、双臂与腰部实测姿态。
- `arm7_action.dat`：兼容原版的双臂 14 轴关键点；尚未审核，不能直接用于原版快速回放。
- `metadata.json`、`session.jsonl`：单位、范围和事件。

内部角度 rad、速度 rad/s，界面显示 °。数据不包含私钥，也不证明指尖达到离地 130 cm 或按钮触发。

证据：[录制前只读状态](../../artifacts/g1-arm-teach-play-20261015/recording-ready.json)、[构建与报文自检](build-result.json)、[适配来源](source-manifest.json)。
