## 已实现

- 独立本地三维预览，右臂 7 轴、长条连杆和球形关节；拖动旋转视角，滚轮缩放，正面/侧面切换。
- 显示目标高度、官方 RH56DFTP 食指网格几何端点高度和差值。高度相对假设的水平地面，单位 cm；关节显示度，内部弧度。
- 已核对 G1 本体与宇树官方文件逐字节一致，纳入官方 FTP 安装变换、食指两关节和远端联动比例 1.0843。现场灵巧手型号已由用户确认是 RH56DFTP。
- 肩前后摆、肘、腕俯仰的高度候选搜索；其他四轴保持当前编辑值。为避免高度问题无穷多解，优先选择前向、水平的食指方向和较小关节变化。
- 抬手—保持—放下的单次几何预演；放下参考可手动设定。五次平滑插值按预览速度估计时长，不代表实物速度设置。
- 离线姿态导入/导出，校验模型版本、关节顺序、数值和 URDF 范围。输出始终标为未授权执行、未标定。
- 本地自带 Three.js r180 与许可证，无 CDN 或网络依赖；预览页禁止网络连接，不包含机器人或管理接口。

## 几何来源与限制

本体模型来自参考仓库提交 `dd6ea93c632247651464308abae847f234b2ccf4` 的 `model/g1_29dof_rev_1_0.urdf`，原样提取右肩至右腕 yaw 的关节原点、旋转轴和上下限，哈希保存在 `web/model.mjs`。已验证该文件与宇树官方提交 `5994d4faef0a9cadd3287f8de0199a67eeb2a259` 的本体模型逐字节一致。手部来自同一官方提交的 `g1_29dof_rev_1_0_with_inspire_hand_FTP.urdf` 和食指网格，数据保存在 `web/hand-geometry.mjs`。详细核对见 `OFFICIAL_DIMENSIONS.md`。坐标按躯干直立、X 向前、Y 向左、Z 向上解释。第一肩关节原点锚定为输入的离地肩高；此页面不求解腿部、腰部或躯干倾角。

用户于 2026-10-13 提供测量：**脚底到肩膀最高点 110 cm**，因此 130 cm 目标比肩顶高 20 cm。这不是肩关节轴心高度。页面将肩顶和“轴心低于肩顶”分别输入，轴心高度 = 肩顶高度 − 偏移；偏移默认 **0 cm 仅作示意，未测量**。此前的 16 cm 单点示例已被官方手部关节链和网格端点替代，未再用于当前页面计算。几何指尖仍未做实际接触点标定，模型结果不能作为实物精度承诺。默认关节为模型零位，模型零位并不等于安全放下姿态。

现场测量的 20 / 13 / 6 / 16 / 5 / 5 cm 仅作对照保存，不覆盖官方原点。官方肩轴到肘轴约19.29 cm；食指两转轴间距约3.28 cm，和指节外壳长5 cm不能互换。食指弯曲滑条表示离线模型角度，远端关节按官方 mimic 比例联动，不是原始寄存器值。导出包含官方手部版本和模型角度空间标记。

自动候选的预览搜索窗口是肩 pitch −140° 到 20°、肘 0° 到 100°；其余轴保持当前值，腕 pitch 按水平指向求解并检查 URDF 限位。搜索窗口和 URDF 范围均不是已验证的实物安全运动范围。候选只保证模型中的高度误差不超过 0.5 cm；该数值是求解容差，不是实物定位精度。

不验证自碰撞、按钮接触力、整机平衡、SDK 控制权或行走互锁。页面没有运动发布器、灵巧手写接口、导航发送接口。不能把导出文件直接作为已验证的实物指令。

历史快照按钮使用 2026-10-13 的只读状态，非实时连接。快照只包含右臂关节角，不包含地面、站姿或指尖标定。

用户提供的现场照片已放入页面作外观参考，可见吊架保护下双臂下垂。照片没有尺寸标尺；不据此量取肩高、推定状态机或改变 URDF/SDK 关节零位。

## 实物接口调查记录

在用户要求切换为纯离线之前，已核实管理接口所在环境为 Ubuntu 20.04.6、Python 3.8.10、x86_64；本地 SDK 包版本标记 2.0.0，arm API 头文件版本 1.0.0.14。这些是安装文件版本，不代表已验证的 MCU 固件版本。

独立只读工具 `readonly/g1_arm_state.cpp` 在新临时目录编译，使用 `enp132s0`、DDS domain 0 订阅 `rt/lowstate`。3 秒收到 3100 帧，CRC/数值拒收 0 帧，最终状态新鲜，未发运动指令。证据保存在 `../artifacts/g1-arm-passive-probe-20261013.json`。该工具没有发布器或运动客户端。

`readonly/g1_mode_query.cpp` 仅含 GetFsmId/GetFsmMode/GetActionList 查询。早期离线阶段一次排队操作被自动审批拒绝；随后用户恢复实机调试，已编译并查询到旧环境 FSM 501、mode 0。该记录不能代表迁移后当前状态。旧被动工具还曾在 DDS 退出时断言，适配版本调整了退出顺序，验证情况见新环境报告。无需为离线预览启动只读工具。

此前获准的 2° 右肩试动在接管阶段触发保护并中止，未完成前向动作。随后用户曾要求环境迁移期间停止控制。

## 后续任务边界

1. 离线高度：在已核对官方几何基础上，补充肩顶到轴心、安装方向和实际接触点标定，选定放下参考与抬手候选。
2. 近按钮阶段：再提供按钮相对位置/法向、按压行程和触发反馈，加入接近、按压、撤离路径；原始手指写值以仓库和现场已验证范围为准。
3. 实物阶段：另行确认具体动作范围、当前站姿、清场、现场监护和急停/手柄可用。必须验证新鲜状态、单一控制者、受限速度、失联处理与交还控制权；不复用旧工具退出不释放 arm_sdk 的行为。
4. 行走衔接：撤离按钮、回到已验收的放下姿态、确认释放控制权与站立状态后，才交给既有导航。导航目标尚未给定；异常或按压失败不自动行走。

开发不修改灵巧手、导航或语音服务，不提交或推送仓库。
