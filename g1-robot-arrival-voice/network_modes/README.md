# G1 有线 / Wi-Fi 双方案（2026-10-10 离线待验收版）

适用现场：导航宿主机 `192.0.2.5`、容器 `nav_robot`（Ubuntu 20.04 / Python 3.8.10 / ROS Noetic / x86_64），G1 固件 1.5.3，机器人 Wi-Fi `192.0.2.18`。初版在机器人关机时完成源码、配置、隔离编译、模拟测试和打包。后续开机无线检查尚未通过 DDS 发现阶段，候选桥接仍未实机启用、未替换旧桥接。

| 项目 | 接网线 wired | 不接网线 wifi |
|---|---|---|
| 宿主机到机器人 | `enp132s0 / 192.0.2.6` | `wlp131s0f0 / 192.0.2.5 → G1 wlan0 / .2.83` |
| 内部控制器 / 雷达 | `.123.161 / .123.120`，原直连路径 | G1 上位机在 wlan0 与内部 eth0 间转发 |
| DDS | SDK domain 0 默认有线发现 | 每次在 G1 eth0 临时加入发现组播并接收当前端口，明确单播 peers |
| 导航接收地址 | 保留 `.123.10` | Wi-Fi 临时添加 `.123.10/32`，保留雷达目标地址 |
| 网络改动 | 不修改地址、路由或 NAT | 3 条 host /32 路由、6 条 NAT 例外；机器人返回路由、1 个 proxy ARP、8 条转发例外 |
| 退出 | 退出候选桥接，不执行 Damp | 先退出候选桥接，再按本次标记回退两端网络 |
| 音频 | 原 SSH 音频服务 / 18768 | 同一音频服务，不改接入方式 |

两个模式显式选择，不自动切网，不并用 `.123.10`。Wi-Fi 模式仍拒绝有线 IPv4 存在。默认只读，不自动站立、Start、Damp、切换 FSM 或自动启动导航。

发现阶段使用 socket 生命周期内的 `239.255.0.1` 成员资格，接收 35 秒；内核可能发送 IGMP，程序不发送 DDS 或运动指令。结束自动关闭自身组播接收套接字，不移除其他程序的成员资格。发现失败会保存并显示诊断结果，在任何路由、防火墙配置前退出。

## 交付文件

- `wired.json`、`wifi.json`：两套现场配置；默认只读。
- `profiles.py`：离线查看方案，验证发现结果并生成 Wi-Fi DDS XML。
- `check_wired.sh`：保持旧有线桥接的只读状态、雷达验证。
- `../wifi_access/start_check.sh`：保留旧桥接的限时无线只读检查，暂停/恢复过程及回退见该模块 README。禁止在此检查期间导航。
- `session.py`、`start_mode.sh`：候选桥接的有线 / Wi-Fi 受监护会话、心跳和回退。
- `bridge.cpp`、`guard.hpp`：独立受保护桥接，输出 `/sdk/imu` 的控制会话以及 `/g1_network/imu` 的只读会话。
- `navigation_limits.yaml`：候选低速会话参数，尚未加载到现场导航。
- `test_*.py`、`test_guard.cpp`：模拟测试，不调用机器人运动接口。
- `verify_bundle.py`：校验离线包 SHA256 清单，不安装或启动程序。

候选程序与源文件隔离暂存于导航容器 `/opt/g1-arrival-voice/network-modes-20261010`；旧 `/catkin_ws` 桥接、地图 1009、导航到达阈值、任务语音和音频配置均未替换。

## 现在可离线运行

在解压包根目录，无需机器人即可查看两套方案和校验文件：

```bash
python3 network_modes/profiles.py wired
python3 network_modes/profiles.py wifi
python3 network_modes/verify_bundle.py .
```

只有显式 `--run` 才连接或启动会话。不要将 Windows 上的 C++ 二进制当成本机程序运行；所附二进制针对已核对的 x86_64 导航容器及其 SDK / ROS 库。

## 充电开机后的验收顺序

先取消任务和导航，机器人稳定、通道清空、有人监护，硬件遥控停止可用。没有实机数据时不能跳过这些检查。任何零速度发送或 RPC 成功都不能代替现场停止确认。

1. 保持网线，在导航宿主机运行 `bash network_modes/check_wired.sh`；确认 FSM 501、LowState 和雷达新消息。原页面点云缺失仍需检查 SLAM 输出与前端连接，不能由驱动有数据推定已恢复定位。
2. 无线只读验收时拔下“导航宿主机 ↔ G1”网线，雷达仍接机器人内部交换机，运行 `bash wifi_access/start_check.sh`。输入现场确认、SSH/sudo 密码；密码只在终端输入。必须得到 DDS、雷达新数据和两端 `rolled_back / remaining: []`，不能只看 ping。
3. 候选桥接控制会话前，需受控停用旧 `g1_ros1_sdk` 的自动启动并停止该旧进程。旧程序退出会执行 Damp，旧程序重启会 StandUp → Start，因此这一步只能在开机后的现场交接中处理。新会话发现旧桥接仍在会直接拒绝，不自行杀进程或重启容器。本轮没有执行交接。
4. 首先使用不带 `--motion` 的候选只读会话，确认状态。随后才使用带 `--motion` 的受监护控制会话；它启动后仍未 armed。

在导航宿主机解压目录选择：

```bash
# 保留网线：候选只读会话
bash network_modes/start_mode.sh wired --run
# 拔除宿主机到机器人的网线：候选 Wi-Fi 只读会话
bash network_modes/start_mode.sh wifi --run
```

Ctrl+C 结束当前会话；切换模式前必须核对回退结果。没有自动有线 / Wi-Fi 切换，也不安装开机服务。每次会话最多 30 分钟，结束后重新检查再启动；SSH 会话和两端临时网络资源不会跨重启自动恢复。

## 控制会话的显式解锁

在完成上述验收和旧桥接交接后，在相同命令末尾加 `--motion`。先按现场位置重新定位；导航速度应设置为不超过候选会话上限。`navigation_limits.yaml` 提供准备值，但未自动加载；加载后需检查规划器实际生效，超过上限的指令会锁定停止。

程序打印本次唯一 `arm_service` 和 `status_topic`。从容器中查看该状态；只有 `healthy: true`、FSM 501、定位正常、现场准备好后，才对打印出的服务执行 `std_srvs/SetBool {data: true}`。用 `{data: false}` 解除 armed。服务路径每次变化，避免沿用上次会话。

候选会话上限是本次低速测试限制，不是 G1 厂商极限：机体坐标系 x/y 速度分别不超过 `0.30 / 0.20 m/s`，yaw 不超过 `0.30 rad/s`。拒绝 NaN/Inf、超限、latched 速度、以及 Twist 中被旧桥接当作站立/卸力命令的非零 linear.z。只使用已在此现场读回 501 的运动状态；不规避固件 1.5.3 的 802 控制问题。

每次速度使用现场 SDK 已提供的 `SetVelocity(vx,vy,yaw,duration=0.30)`，不再采用旧桥接的 864000 秒持续模式。指令超过 0.30 秒、LowState 或雷达超过 0.50 秒、FSM 查询超过 2.50 秒或 FSM 非 501、速度 RPC 失败/结果不确定时解除 armed 并锁定；网络恢复后不会自动恢复运动，也不会重放解除 armed 前的指令。重新解锁后必须收到新指令。

主控进程心跳停止后，候选桥接在 15 秒内退出，退出前对曾提交过速度的控制会话尽力发送零速度。无线网络租约在初始 180 秒安装宽限后，30 秒未收到新心跳会回退，硬上限 1 小时；正常会话 30 分钟主动结束。正常退出先结束候选桥接，再回退网络。无线断连时零速度可能送不到；固件是否按 0.30 秒 duration 停止仍必须实机验证，不能宣称断网停车已经通过验收。硬件遥控停止仍是现场停止路径。

## 导航任务与播报

两套网络方案沿用原导航页面、地图点位、`导航 → 语音播报 → 下一导航` 的任务步骤和已安装的语音模块。音频服务继续使用现有启动脚本与机器人 Wi-Fi SSH；不会改为另一种音频接入或保存密码。

先有线、再无线，各自验收一次地图 1009 的 2 点 → 语音步骤 → 3 点 → 语音步骤。文字 TTS 仍只有提交回执；“等说完再下一步”需保留任务的等待时间。WAV 继续按音频流时长等待。旧导航 `13` 没有任务 ID 的限制保持原有约定，不能用 `12` 或机器人静止代替真实到达。

## 回退与验证边界

候选包未替换旧可执行文件，因此本轮回退只需不启用候选包。会话结束会保存本次两端网络回退回执；不删除其他路由、防火墙规则或全局 conntrack。回退失败或机器人不可达会明确报错，不当作回退成功；恢复网络前不要启动导航。

有线的默认 DDS 查询、动态发现端口后的单播查询曾在机器人有电时只读成功，FSM 501；但这是本次候选桥接编写前的连接证据。当前候选桥接只完成隔离编译和模拟测试，尚未实机启用。无线完整数据链路、有限时长指令的固件行为、断线停止、SLAM 点云显示、原任务播报均保留为开机后验收项。
